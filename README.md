# ⚙️ Run Locally

Since this is a static website, no backend server or database is required.

### 1. Clone the repository

```bash
git clone https://github.com/Hacker-Hima/Himachalam-portfolio.git
```

### 2. Navigate into the project

```bash
cd Himachalam-portfolio
```

### 3. Open the project

You can simply open:

```text
index.html
```

in a browser.

Or use **VS Code Live Server** for development.

---

# 🔧 Development

Recommended setup:

* Visual Studio Code
* Google Chrome / Microsoft Edge
* Live Server extension

### Using Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website will open in your browser.
